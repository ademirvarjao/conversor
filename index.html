    Conector LLM Opcional (OpenAI / Gemini)

    O Conversor funciona 100% offline com IA local. Opcionalmente, informe uma chave própria para analisar layouts inéditos via nuvem. A chave fica salva apenas neste navegador.

    Conta na nuvem recomendado

    A chave de acesso protege o conteúdo (o banco só guarda texto cifrado). A conta protege o acesso: com ela, o banco entrega e aceita apenas os cofres dela — ninguém mais lê, sobrescreve ou apaga os seus modelos, nem com a chave pública do projeto.

    É uma conta do Supabase Auth do seu projeto (e-mail + senha). A senha não fica guardada no app: só os tokens da sessão, neste navegador. Se o projeto exigir confirmação de e-mail, confirme antes de entrar.

    Modelos treinados no banco compartilhado

    Os modelos aprendidos (pesos semânticos, perfis de layout, log e as contas treinadas no conciliador) ficam no banco compartilhado do Conversor, cifrados neste navegador com a sua chave de acesso. Os arquivos e os lançamentos financeiros nunca saem daqui.

    Carregando…

    A tabela do banco ainda não existe neste projeto. Copie o SQL de instalação, cole no SQL Editor do seu projeto Supabase e rode uma vez (Run). É idempotente: pode rodar de novo sem quebrar nada.

    Abrir SQL Editor

    O SQL já termina em notify pgrst, 'reload schema';, então o banco passa a responder na hora. Se a tabela já aparecer no Table Editor e este aviso continuar, rode apenas notify pgrst, 'reload schema'; e clique em Verificar de novo.

    Com a integração Supabase + GitHub ativa (Production branch main e supabase/config.toml no repositório), a próxima migração entra sozinha e este aviso nunca mais aparece.

    1. Sua chave de acesso

    Sem senha e sem cadastro: a chave é a sua identidade. Ela também serve para recuperar os modelos em outro computador.

    Sua chave de acesso — guarde com você: é com ela que você abre seus modelos em outro computador.

    Em outro computador, informe esta chave para recuperar seus modelos. Quem tiver a chave acessa os modelos — não compartilhe.

    2. Sincronizar

    O envio acontece automaticamente depois de cada treinamento e também ao criar a chave. O download substitui os modelos deste navegador pelos da nuvem (a chave do LLM continua só aqui).

    3. Conexão do banco administrador

    Só o administrador troca a conexão do banco — a Project URL e a chave pública do Supabase — ou aponta o app para outro projeto. O resto da nuvem fica livre para todos: consultar a chave de acesso, enviar e baixar modelos.

    A liberação vale só para esta aba do navegador e expira em 1 hora (ou ao clicar em Bloquear acesso). O login e a senha são conferidos no seu computador — nenhuma senha é enviada para o servidor.

    Conexão com o banco (avançado)

    O banco é criado e mantido pela integração Supabase + GitHub: a migração supabase/migrations/20261111120000_conversor_models.sql é aplicada a cada push na main. Só mexa aqui para apontar o app para um projeto Supabase próprio.

    Onde estão os dois valores (painel do Supabase): Project Settings → API — copie a Project URL e a chave anon public. Elas são públicas por natureza: quem tiver a chave lê apenas texto cifrado. Nunca use a service_role.

    Além do botão, a conexão volta a ficar bloqueada ao fechar o navegador ou depois de 1 hora.
