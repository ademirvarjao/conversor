    Portabilidade da Memória (GitHub / Equipe)

    Exporte a memória aprendida em JSON para versionar no seu repositório GitHub ou compartilhar entre máquinas.

    Conector LLM Opcional (OpenAI / Gemini)

    O Conversor funciona 100% offline com IA local. Opcionalmente, informe uma chave própria para analisar layouts inéditos via nuvem. A chave fica salva apenas neste navegador.

    Modelos treinados no banco compartilhado

    Os modelos aprendidos (pesos semânticos, perfis de layout e log) ficam em um banco compartilhado, cifrados neste navegador com a sua chave de acesso. Os arquivos e os lançamentos financeiros nunca saem daqui.

    Carregando…

    1. Sua chave de acesso

    Sem senha e sem cadastro: a chave é a sua identidade. Ela também serve para recuperar os modelos em outro computador.

    Sua chave de acesso — guarde com você: é com ela que você abre seus modelos em outro computador.

    Em outro computador, informe esta chave para recuperar seus modelos. Quem tiver a chave acessa os modelos — não compartilhe.

    2. Sincronizar

    O envio acontece automaticamente depois de cada treinamento. O download substitui os modelos deste navegador pelos da nuvem (a chave do LLM continua só aqui).
